# 사이트 설계도(PRD) — 급여 자동계산 (매장 근무시간 기록)

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
각 지점 점장이 매일 직원별 출·퇴근 시각을 적으면, 일한 시간이 매일 자동으로 더해져 한 달 뒤 직원별 총 근무시간이 나오는 우리 매장 전용 도구.

## 2. 쓰는 사람
- 누가: 우리 매장 각 지점의 점장 (외부 손님용 사이트가 아님 — 내 매장에서만 씀)
- 예전처럼 엑셀을 모두 같이 보던 방식 그대로: 모든 지점을 모두가 같이 보고 적는다
- 어디서 들어오나: 사장님이 점장에게 주소를 직접 알려 줌 (검색에 노출할 필요 없음)

## 3. 점장이 화면에서 바로 알고 싶은 것
1. 오늘 우리 지점 직원별로 몇 시간 일했나 (출·퇴근 시각 → 자동 계산)
2. 이번 달 지금까지 직원별로 몇 시간이 쌓였나 (매일 업데이트)
3. 한 달이 끝났을 때 직원별 총 근무시간

## 4. 믿게 할 증거 (실제로 있는 것만)
- 계산 방식 안내: "근무시간 = 퇴근 시각 − 출근 시각" 을 화면에 한 줄로 보여 준다
- 계산 범위 안내: "총 시간만 보여 줍니다. 급여·주휴수당·세금은 계산하지 않습니다"
- 후기: (해당 없음 — 내부 도구)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 기록 저장
- 누르면: 오늘 기록이 저장되고, 이번 달 직원별 누적 시간이 바로 바뀐다

## 6. 페이지 구성
1. 들어가기 — 공용 비밀번호 하나 (점장 계정 없음)
2. 오늘 기록 화면 — 날짜 + 직원별 출근·퇴근 시각 입력칸 + 기록 저장 버튼 + 오늘 근무시간
3. 이번 달 합계 화면 — 직원별 이번 달 누적 근무시간 (큰 숫자, 표)
4. 지난 기록 보기 — 날짜를 골라 이미 적은 기록 확인·고치기
5. 한 달 표 (/month) — 예전 엑셀 시트와 같은 모양. 세로 날짜(1일~말일) × 가로 직원별 [시작·종료·시·분], 맨 아래 합계 줄. 칸을 바로 고치고 한 번에 저장

## 7. 기록할 것 (입력칸)
- 날짜 (기본: 오늘)
- 직원 이름 (지점별 직원 목록에서 고름)
- 출근 시각, 퇴근 시각
- 일한 시간 = 퇴근 시각 − 출근 시각 (사이트가 자동 계산)
- 한 달 총 시간 = 그 달 일한 시간을 모두 더한 값
- 직원 이름·근무시간은 개인정보이므로 저장한다면 개인정보 처리방침이 필요하다

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 결과: 총 근무시간만 (급여 계산 안 함)
- 대상: 아르바이트만 (정직원 등 다른 구분 없음)
- 기록하는 사람: 각 지점 점장
- 들어가는 방법: 공용 비밀번호 하나 (Vercel 환경변수 ADMIN_PASSWORD). 화면 위에서 지점을 고른다
- 지점 이름·개수: (미정)
- 지점별 직원 목록: (미정)
- 휴게시간을 빼는지: 지금은 빼지 않음 (화면에 안내). 바꾸려면 말씀해 주세요
- 자정 넘는 근무(예: 22:00~02:00): 퇴근이 출근보다 이르면 다음 날 퇴근으로 계산 (4시간)
- 지점 관리: /admin — 지점 추가·이름 바꾸기, 지점별 한 달 합계 (같은 공용 비밀번호)

## 9. 이번에 넣지 않을 것
- 급여 계산(시급 × 시간), 주휴수당·야간수당
- 세금(3.3%)·4대보험 공제
- 직원이 직접 출·퇴근 찍기
- 엑셀(CSV) 내려받기
- 알림 메일·문자

## 10. 첫 화면 한 문장 후보
1. 출·퇴근 시각만 적으세요. 한 달 근무시간은 알아서 더해 드려요.
2. 점장님, 오늘 우리 지점 근무시간을 1분 만에 기록하세요.
3. 매일 적고, 월말엔 직원별 총 시간을 한눈에.

## 11. 다음에 할 것
- 시급을 넣어 직원별 한 달 급여까지 계산
- 엑셀(CSV) 내려받기
- 주휴수당·야간수당 계산
- 직원이 직접 출·퇴근 기록

- 하루에 한 직원당 기록 1개 (쪼개서 두 번 일한 날은 다음에)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 기록 저장: 예 → Supabase(leaderpl-admin 스킬)
- 회원가입: 없음 — 2026-10-18 점장별 로그인에서 공용 비밀번호로 바꿈(엑셀처럼 모두 공유). 개인정보 처리방침 자리는 남겨 둠
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 '따뜻한' 분위기에 맞게 정하고 로그인 → 오늘 기록 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. Supabase에 지점·직원·근무기록 저장 → 점장별 로그인 → 이번 달 합계 화면까지 만든다
4. 휴대폰 화면에서 입력·합계가 잘 보이는지 확인한다
5. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 점장 로그인 방법 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): GitHub·Vercel·Supabase 로그인, 점장 계정 비밀번호 정하기
