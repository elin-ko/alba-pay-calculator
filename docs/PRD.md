# 사이트 설계도(PRD) — 알바 급여 계산기

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
시급과 하루 근무시간(그리고 한 달 근무일수)을 넣으면 하루 급여와 한 달 급여(주휴수당 미포함)가 바로 나오는 알바 급여 계산기.

## 2. 손님
- 누가: 알바생을 둔 사장님, 가게 매니저·점장
- 어디서 알고 오나: 지인 소개·단톡방(아는 사장님끼리 링크 공유)

## 3. 손님이 궁금한 것 (계산하기 전에)
1. 우리 알바생 하루 급여가 얼마인가
2. 이번 달 급여를 얼마 줘야 하나
3. 이 숫자가 어떻게 나온 건가 (주휴수당은 들어 있나?) → 화면에 "주휴수당 미포함"을 분명히 적는다

## 4. 믿게 할 증거 (실제로 있는 것만)
- 계산 기준 안내: "주휴수당·야간수당·세금은 포함하지 않은 금액입니다"
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 계산하기
- 누르면: 바로 아래에 하루 급여 · 한 달 급여가 나온다 (문의 폼 없음)

## 6. 페이지 구성 (위에서 아래로, 한 장)
1. 첫 화면 — 한 문장 + 입력칸 + 계산하기 버튼
2. 계산 결과 — 하루 급여, 한 달 급여 (큰 숫자)
3. 계산 기준 안내 — 주휴수당 미포함 등 포함하지 않은 것
4. 후기 자리 (비워 둠)

## 7. 계산기에서 받을 것 (입력칸)
- 시급 (원)
- 하루 근무시간 (시간)
- 한 달 근무일수 (일) — 처음엔 비워 둔다. 기본값을 대신 정하지 않는다
- 계산식: 하루 급여 = 시급 × 하루 근무시간 / 한 달 급여 = 하루 급여 × 한 달 근무일수
- 입력한 값은 어디에도 저장·전송하지 않는다 (개인정보 동의 불필요)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 무료 계산기 (미정 — 따로 말하지 않음)
- 시간: (해당 없음)
- 위치: (해당 없음)
- 연락 방법: (미정)
- 계산 범위: 주휴수당 미포함

## 9. 이번에 넣지 않을 것
- 주휴수당·야간수당
- 세금(3.3%)·4대보험 공제
- 문의 폼·관리자 페이지(/admin)
- 회원가입·로그인·계산 기록 저장
- 직원 여러 명 한 번에 계산

## 10. 첫 화면 한 문장 후보
1. 시급이랑 근무시간만 넣으면, 알바 급여가 바로 나와요.
2. 사장님, 이번 달 알바 급여 계산은 여기서 10초면 끝나요.
3. 복잡한 표 없이, 하루 급여와 한 달 급여를 한눈에.

## 11. 다음에 할 것
- 주휴수당 계산 (주 15시간 이상일 때)
- 야간수당 계산
- 3.3% 세금 / 4대보험 공제한 실수령액
- 문의 폼 + Supabase 저장 + /admin
- 회원가입·로그인 + 직원별 계산 기록 (이때 개인정보 처리방침 필요)
- 직원 여러 명 한 번에 계산·합계
- 단톡방 공유용 "링크 복사" 버튼, 계산식 한 줄 보여 주기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 아니오 (계산은 브라우저 안에서만)
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 '따뜻한' 분위기에 맞게 정하고 첫 화면(입력칸 + 계산하기 + 결과)부터 만든다
2. 휴대폰 화면에서도 입력·결과가 잘 보이는지 확인한다
3. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): GitHub·Vercel 로그인
